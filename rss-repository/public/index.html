Public access

Expose your feeds to the internet via a free Cloudflare Tunnel, so cloud services like Zapier or Inoreader (or Claude/Gemini's web apps) can fetch a group's feed directly. This uses Cloudflare's no-signup "quick tunnel" — the public address is random and changes every time you restart it, so re-point any automation after a restart. It's also unauthenticated: treat a public feed URL as effectively public once you share it.
